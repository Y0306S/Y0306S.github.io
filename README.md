# chua yuan shan

Personal site. Static HTML for GitHub Pages.

Live: https://y0306s.github.io/

## Local

From this folder, once:

```bash
pip install livereload
```

Then:

```bash
python serve.py
```

Opens `http://127.0.0.1:5500/`. Save HTML or CSS and the browser reloads. There is no compile step.

## Pages

- `index.html` — about
- `work.html` — selected work
- `cv.html` — HTML cv, with PDF at `cv/Yuan_Shan_CV_BF_2.pdf`
