Dubbing as speech models

iQIYI International · full stack intern · Aug 2026 – Jan 2027

The problem

A dubbed line has to do three things at once. It has to sound like the same person. It has to fit the mouth that is already on screen. And it has to carry the emotion of the original, not a polite mid tone that makes every scene feel like a trailer.

The factory that queues those jobs and mixes the stems is the other page. This one is how we chose voices, compared models, and tried not to fail a whole episode because one role or one language was awkward.

TTS is not the same job as cloning

Some markets we synthesise from text. Some we convert from a reference clip so the timbre stays close to the original actor. Those are different models, different request shapes, and different failure modes. Mixing them up in the UI — showing the wrong “TTS” url, sending a clone id as a text-model param — is how a character disappears from an episode.

Before an editor sits down we try to make a first pass: map speakers to timbres, pick a reference clip per line, submit TTS or voice conversion, and wait. Each line becomes a short wav tied to a subtitle row. If Thai has no speaker map for a role, we skip that voice instead of failing the episode. Manual conversion is one job per speaker. Smash every role into one request and someone vanishes.

Spanish and Portuguese needed speaker injection restored on subtitle supply, plus a frontend model id that is not the id the backend wants. That kind of lie is how you keep a dropdown readable. Rewrite-only tasks fall back to Chinese if there is no English reference, and we hide the algorithm picker so nobody submits an empty produce.

Which model, and for what

I spent a stretch comparing and fine-tuning TTS and voice-conversion models for cross-lingual inference: GPT-SoVITS, Qwen-3.0-TTS, Seed-VC, Chatterbox. The question was not “which demo sounds nicest on one sentence.” It was whether a line still holds after you change language, stretch duration, and sit it under music.

Background characters are a different mess. You often do not have a clean reference for them. I evaluated and fine-tuned speech emotion recognition — emotion2vec, and a fine-tuned wav2vec2 — so we could pull emotion- and timbre-matched reference audio for those roles instead of giving everyone the same polite voice.

“Is this the same person” is its own small service: speaker embeddings (ERes2Net) so ASR GPUs and embedding GPUs can scale separately. Whisper needed word timestamps off an audio URL. The faster wheels did not install cleanly on the old glibc box — tiktoken wanted Rust, intranet PyPI was picky — so the official openai-whisper build with a pinned tiktoken was the one that actually ran. The GPU box also cannot see internal buckets, so the audio URL has to be public object storage.

Mouths, not just words

AI lines are wrong often enough that we built a human loop. GPT rewrite prompts are versioned by language. Timing is one reason. The last mouth shape is another. For English we map the last Chinese final, via pypinyin, into closed / rounded / open / neutral ending sounds so the mouth is not on “ee” when the Chinese was “ang.” The rounded viseme list forgot the final “o” until a hotfix, which is a small sentence that still makes me wince.

Prompt iteration is faster than baking a new image, which is why the worker can pull and restart — the ops of that restart lives on the software page. The modelling lesson is simpler: the prompt is part of the product, and it changes after you ship.

What still sounds fake

One missing map should skip a voice, not kill the episode. Re-dub should copy source subtitle rows, mark reused refs as ready, and not keep an old reference if the source line was deleted. In-house versus a vendor changes which URL even counts as “the TTS.”

I would still want contract tests on the gateway payloads, and a clearer split between “this model id is what editors see” and “this id is what synthesis actually wants.” The interview version of this work is not the model card. It is whether a line can get onto a timeline, survive a split, and still sound like the same person.
